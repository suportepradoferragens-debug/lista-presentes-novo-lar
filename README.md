# Lista de Presentes — reconstruída

Projeto Next.js reconstruído a partir das alterações recuperadas do Codex.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Fonte dos presentes

Por padrão, `/api/gifts` encaminha GET e POST para a API da versão publicada anterior:
`https://lista-presentes-novo-lar.suportepradoferragen.chatgpt.site/api/gifts`

Para trocar a origem, configure `LEGACY_GIFTS_API`.
